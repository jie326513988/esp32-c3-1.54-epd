# 项目说明

![输入图片说明](%E5%9B%BE%E7%89%87/%E7%88%86%E7%82%B8.jpg)

- epub阅读、txt阅读、midi音乐、闹钟、时钟、表盘、天气、配网、设置、文件管理器
- 由ESP32MP3墨水屏阅读器精简而来，只阉割了MP3音频
- 添加了蜂鸣器，可以播放midi音乐，当闹钟用
- 精简电路，元件少，焊接简单，外壳好打印，比较适合新手
- 原理图和PCB，浏览器的右上角点击打开编辑器就能看了
- BOM已校对，立创商城可直接下单，如有缺货自行替换
- 字体&SD卡WIKI
- MIDI音乐下载
- 视频合集


# 制作注意事项

- 板厚1.0
- ESP32-C3要后缀为FH4的版本，因为自带4mb的Flash，板子没有Flash芯片
- ESP32-C3FH4用锡膏+热风枪或加热台比较好焊
- 屏幕插座前面的一排电容最好用绝缘胶纸贴好，防止接触到排线短路
- 屏幕插座不要焊歪，不然外壳装配屏幕会歪不好看
- 刷入固件后会弹出按键校准界面，按提示依次按下按键即可，途中按错按重启即可重新校准
- 未激活设备未做功能限制，仅提示未激活，自制的每人限激活2台，从外面卖的未授权设备不帮激活

空片上电会一直断开连接不用理会，直接烧录即可

注意，由于win7系统不自带winusb驱动，请升级至win8以上系统，或前往乐鑫原厂手册安装驱动

1.选择esp32-c3，USB模式

2.选择路径，记得打钩，烧录地址0x0，注意是零叉零，不是欧叉欧

3.选择com口，没有就多点几次

4.选择波特率，直接拉满

5.点击START开始，失败就多点几次

# 硬件设计
主控 ESP32-C3FH4   集成4MBFlash
贴片天线，陶瓷和PCB天线都没毛病，但未做阻抗匹配
TYPE-C接口，充电和烧录程序用
锂电池充电管理 LTH7R/4054
USB/电池自动切换电路，二极管+PMOS管实现
3.3V-LDO ME6210A33M3G
时钟 RX8010SJ
温湿度  SHT30-DIS-B10KS
电池电压采样使用2颗300k电阻分压，设置中心内可校准分压系数
使用4颗凯华长寿按键，使用ADC按键的方式，首次刷入自动弹出校准界面校准ADC按键
复位按键使用小侧按
使用贴片蜂鸣器，三极管驱动，用于播放midi音乐和闹钟
TF卡使用mos管控制开关，休眠时关闭，节省电量




# 操作说明

隐藏的外壳按键为复位，按下会重启

当出现黑底白字的实心选框，则表示按键3、4有长短的功能




# 常规界面

短按按键1、2：切换选项

短按按键3：返回

短按按键4：确认




# 带列表的界面

短按按键1、2：切换选项

短按按键3、4：换页

长按按键3：返回

长按按键4：确认




# 键盘界面

短按按键1、2：左右

短按按键3、4：上下

长按按键3：返回

长按按键4：确认
